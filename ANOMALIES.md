## 1. Неверные ссылки в формате Markdown

Во многих строках поле `site` записано так:

[https://example.ru](https://example.ru)

Это не обычный URL, а Markdown-ссылка. Такое значение нельзя напрямую использовать как URL сайта.

Пример:

c_001005

Фактическое значение:

[https://ip-815.ru](https://ip-815.ru)

Ожидаемое значение:

https://ip-815.ru

## 2. Некорректное значение rating: N/A

Компания:

c_001083

Значение:

N/A

Поле `rating` должно быть числом или NULL. Значение `N/A` нельзя преобразовать в NUMERIC.

## 3. Десятичная запятая в rating

Компания:

c_001010

Значение:

"4,5"

В основном файле используется десятичная точка. Значение нужно нормализовать в `4.5`.

## 4. Пропущенное значение телефона

Компания:

c_001083

Поле `phone` пустое.

Это не обязательно ошибка, но значение отсутствует.

## 5. Некорректный номер телефона

Компания:

c_001004

Значение:

8 (925) abc-12-34

Номер содержит буквенные символы `abc`.

## 6. Опечатка в городе

Компания:

c_001182

Значение:

Санкат-Петербург

Вероятно, должно быть:

Санкт-Петербург

## 7. Некорректные URL

Компания:

c_001132:

https://

Компания:

c_001020:

htp://sintez-service-453.ru

Во втором случае отсутствует буква `t` в протоколе. В первом URL не содержит домена.

## 8. Некорректное значение сайта

Компания:

c_001064

Значение:

нет сайта

Следует преобразовать в NULL.

## 9. Некорректный rating вне диапазона

Компания:

c_001122

Значение:

-3

Компания:

c_001186

Значение:

7.2

Если рейтинг имеет шкалу от 0 до 5, оба значения недопустимы.

## 10. Некорректный тип reviews_count

Компания:

c_001079

Значение:

45.5

Компания:

c_001187

Значение:

много

Поле `reviews_count` должно быть целым неотрицательным числом.

## 11. Отрицательное количество отзывов

Компания:

c_001116

Значение:

-10

Количество отзывов не может быть отрицательным.

## 12. Неверная кодировка текста

Компания:

c_001008

Поля `name` и `city` содержат mojibake:

РћРћРћ В«Р—Р°СЂСЏ РўРµС…В»

РњРѕСЃРєРІР°

Это признак того, что UTF-8-текст был ошибочно прочитан или перекодирован

## 13. Неверный город Moscow | *если принимаем только Кириллицу

Компания:

c_001108

Значение города:

Moscow

В остальных данных города записаны на русском языке. Вероятно, значение нужно привести к:

Москва

## 14. Лишний пробел в городе

Компания:

c_001184

Значение:

Москва␠

В конце значения есть пробел. Его нужно удалить при нормализации.

## 15. Некорректное значение имени

Компания:

c_001145

Имя записано с удвоенными кавычками CSV:

ООО ""Ромашка""

После корректного CSV-разбора это может быть нормальным экранированием, но результат необходимо проверить. Ожидаемый текст:

ООО "Ромашка"

## 16. Повторяющиеся записи

В файле повторно встречаются компании:

- c_001049
- c_001050
- c_001075

Повтор нужно проверить по `id`. При загрузке следует использовать дедупликацию или `ON CONFLICT`.

## 17. Обрезанный телефон

Компания:

c_001091

Телефон записан как:

+7

Это неполное значение телефона.

## 18. Пустые строки

В конце файла присутствуют две строки:

,,,,,,,,

Они не являются компаниями и должны быть пропущены.


## Методы

 Через LLM. По-хорошему надо написать валидатор для некорректных кодировок,
 а некорректность данных проверять на этапе ввода на стороне сервера, чтобы исключить
 возможность редактирования на стороне клиента

## Дубликаты

SELECT id, COUNT(*)  
FROM review_companies  
WHERE id IS NOT NULL  
GROUP BY id  
HAVING COUNT(*) > 1  
ORDER BY COUNT(*) DESC, id;  

## Некорректные рейтинги

SELECT source_row, id, rating_raw  
FROM review_companies  
WHERE rating_raw IS NOT NULL  
  AND (  
      rating_raw = 'N/A'  
      OR rating_raw !~ '^[0-9]+([.,][0-9]+)?$'  
      OR replace(rating_raw, ',', '.')::numeric NOT BETWEEN 0 AND 5  
  );  

## Количество отзывов

SELECT source_row, id, reviews_count_raw  
FROM review_companies  
WHERE reviews_count_raw IS NOT NULL  
  AND (  
      reviews_count_raw !~ '^[0-9]+$'  
      OR reviews_count_raw::integer < 0  
  );  

## подозрительные сайты

SELECT source_row, id, site_raw  
FROM review_companies  
WHERE site_raw IS NOT NULL  
  AND (  
      site_raw IN ('нет сайта', 'https://')  
      OR site_raw NOT LIKE 'http%'  
      OR site_raw LIKE '[%'  
  );
